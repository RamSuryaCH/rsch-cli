RSCH is a Go-based, provider-neutral terminal coding assistant with an interactive TUI, non-interactive prompts, governed code and shell tools, repository search and context, LSP integration, persistent sessions and workflows, evidence-based verification, and an HTTP/SSE inspection surface. Treat command help as authoritative: human-readable output is still the default, machine output is enabled per command with `--json` or for prompts with `--output-format json`, and potentially destructive or unattended actions require deliberate user authorization.
